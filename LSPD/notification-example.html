🔔 Custom Notifications System

Compatible FiveM NUI - Remplacement des alert(), confirm() et prompt()

📢 Notifications

Remplacement moderne de alert()

showNotification('Message', 'info');    // Bleu
showNotification('Message', 'success'); // Vert
showNotification('Message', 'warning'); // Orange
showNotification('Message', 'error');   // Rouge

✅ Confirmation

Remplacement de confirm()

showConfirm('Êtes-vous sûr ?', function(result) {
    if (result) {
        console.log('Utilisateur a cliqué Oui');
    } else {
        console.log('Utilisateur a cliqué Non');
    }
});

✏️ Prompt

Remplacement de prompt()

showPrompt('Entrez votre nom', 'Jean Dupont', function(value) {
    if (value !== null) {
        console.log('Nom saisi:', value);
    } else {
        console.log('Utilisateur a annulé');
    }
});

🎨 Personnalisation

Options avancées avec texte personnalisé

showConfirm('Supprimer cet élément ?', callback, {
    yesText: 'Supprimer',
    noText: 'Annuler'
});

showPrompt('Commentaire', '', callback, {
    okText: 'Valider',
    cancelText: 'Annuler',
    placeholder: 'Entrez votre commentaire...'
});

📦 Installation

<!-- Dans le <head> de votre HTML -->
<link rel="stylesheet" href="styles/custom-notifications.css">

<!-- Avant vos scripts, à la fin du <body> -->
<script src="scripts/custom-notifications.js"></script>
<script src="scripts/votre-script.js"></script>
