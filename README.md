# LSPD Assistant

LSPD Assistant est un bot Discord accompagné d’un site web, spécialement conçu pour simplifier et automatiser la gestion de la paperasse du Los Santos Police Department (LSPD). Il permet aux officiers de police de créer, suivre et archiver rapidement leurs rapports, infractions et autres documents administratifs.

## Fonctionnalités

- **Automatisation des rapports** : création et envoi simplifiés directement via Discord.
- **Gestion des infractions** : suivi et archivage faciles des amendes et sanctions.
- **Base de données centralisée** : accès sécurisé via le site web pour consulter et gérer l’ensemble des dossiers.
- **Interface intuitive** : commandes claires sur Discord et dashboard web pratique.

## Installation

1. Invitez le bot sur votre serveur Discord avec les permissions nécessaires.
2. Configurez les variables d’environnement (token, base de données, etc.).
3. Lancez le bot et accédez au site pour gérer les paramètres et consulter les dossiers.

## Usage

- Utilisez les commandes Discord pour créer des rapports ou enregistrer des infractions en quelques secondes.
- Connectez-vous au site web pour consulter les rapports, modifier les dossiers et générer des statistiques.

---

LSPD Assistant vise à réduire la charge administrative du LSPD afin que les officiers puissent se concentrer sur leurs missions de terrain.
